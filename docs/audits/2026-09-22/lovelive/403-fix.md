# Love Live! HTTP 403 修复

## 原因与修改

官网公开 HTML 页面及 `image.php` 图片端点会对旧 `LiveDashboard-iOS/1.0` User-Agent 返回 HTTP 403 和通用 NOT FOUND 页面。相同 URL 使用移动 Safari 兼容格式、附加 `LiveDashboard/1.0` 身份后返回 HTTP 200。单独修改 Accept 不能解决问题。

App 在设备端继续使用 URLSession，仅为 Love Live! 官网主机应用该请求头。网页抓取与图片预览、放大、原图下载共用同一请求头定义；不需要服务器、代理、WebView 或登录。真实 HTTP 错误仍然按失败处理。

- 五个官方栏目均恢复 HTTP 200：[栏目请求结果](index-access-after-403-fix.json)。
- 修复前的 20 条 HTTP 403 保留在 [app-live.json](app-live.json)，不覆盖历史证据。
- 已保存修复后 20 个真实官网 HTML 响应及 [SHA-256](capture-after-403-fix.json)；[回放清单](replay-manifest.json) 可供生产解析器离线回归。
- 图片代表样本覆盖 special、hasunosora、uranohoshi、nijigasaki 的 image.php：旧请求返回 403，修复后的请求返回实际图片字节。官网有时把图片错误标为 text/html，app 原有的图片内容检测可正确识别，无需信任 Content-Type。
- iOS 模拟器真实联网：**20/20 详情成功抓取且产生公演日期**；从六个图片路径分组下载的代表性图片均成功解码。不是仅用桌面浏览器验证。
