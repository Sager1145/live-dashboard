# 首页排序与官方缩略图

- 公演日期升序，同日按开演时间；时间未公布的排在同日已公布时间之后，日期未公布的排在列表最后。多日公演以最早日期排序，显示最早到最晚的日期范围。
- 卡片使用官网公演主视觉，保持图片比例；解码时缩至最多 960 像素，避免首页保留完整大图。
- BanG Dream! 使用公演 eyecatch，Love Live! 使用公演主图，排除通用 OGP/Logo。Liella! 三个失效 OGP URL 改为同 img_path 的正文实际图片来源，不拼造图片地址。
- 修复 LoveHigh 将宣传语误当公演标题的问题；标题从该系列事件 og:title 获取。

验证：56 项单元测试与 1 项 UI 测试通过（另一个显式启用的联网测试默认跳过）；60 个官网样本均提取到唯一主视觉，60 个最终图片地址均通过 HTTP 与图片签名检查。原 BanG Dream! 40 场已核验字段回归仍全部通过。
