# 隐私说明

Live Dashboard 是独立公演资料工具。当前 App 直接从 BanG Dream! 与 Love Live! 官网获取公开公演资料，不连接本项目的外部服务器，也不创建服务端安装身份。

## 设备内的数据

公演资料和最近整理时间持久保存在设备的 Application Support 中。关注、选定场次、卡片设置、手动申请／付款记录和个人提醒存储在独立 SwiftData 数据库中。公演资料与个人记录分开保存。未开启 iCloud 同步，也不读取票务账号或自动确认申请／付款结果。

每天首次打开 App 或跨天回到前台时自动访问官网，也可手动整理。请求会向对应官网提供网络连接所需的 IP 地址和常规 HTTP 信息，适用该官网自身的隐私说明。资料在本机解析，不上传个人关注或申请记录。

## 提醒

用户主动设置的提醒通过系统本地通知投递，需要系统通知权限。当前 App 不注册 APNs 远程推送。App 关闭期间不会持续抓取官网；已设置的本地提醒不会保证跟随之后的官方变更，需重新核对并设置。可在系统设置中撤销通知授权。

## ChatGPT 助手（可选）

登录 ChatGPT 账号或填入 API Key 后，使用助手会把官网页面文字与已解析的结构化公演资料发送到 OpenAI 的 API 以生成摘要；不登录时不发送任何数据。登录凭据（ChatGPT OAuth 令牌或 API Key）保存在本机钥匙串（ThisDeviceOnly，不随 iCloud 同步或备份迁移），可在「设置 → ChatGPT 账号与 AI 整理 → 退出登录」中随时删除。生成的摘要与官方资料分开保存在 Application Support 中，不写入公演资料本身。

## 删除与公开来源

卸载 App 会移除其本地存储中的公演资料、关注、申请记录、卡片设置与摘要缓存；钥匙串中的 ChatGPT 助手登录凭据不随卸载清除，会保留至用户在「设置」中执行退出登录为止。重新安装后仅整理当前窗口内及未来的演出，之前保存的历史公演不会自动恢复。

本项目默认不运行第三方广告或行为分析 SDK。第三方官网及商店链接在用户选择后打开，适用该网站自己的隐私说明；App 不代替用户登录、购票或付款。

仓库保留的可选后端包含安装身份、订阅、APNs 等旧接口，当前 App 未启用这些接口。若另行部署并修改 App 使用后端，须按实际数据流更新隐私说明。
