## 生产上线仍需的输入

1. 自有 API 域名、TLS、生产数据库及私有媒体存储位置。
2. 逐来源 robots／条款审查日期、允许路径和素材展示/缓存策略。已取得 HTML 不自动表示素材可再利用。
3. LL02–LL10 可访问的官方页面或经审核导入的完整原始资料；本次没有绕过 403。
4. Apple Team、实际 Bundle ID、APNs key、授权真机和 TestFlight 发布条件。
5. 审核员逐字段批准身份、城市/Day/昼夜场、价格资格和范围；未经批准的跨来源身份不自动合并。

首版不包含未经需求验证的浏览器绕过方案。Playwright 只在某个正常公开且获准页面确实依赖 JS 时按来源增加；当前静态 fixture 不需要浏览器执行。PDF 文本提取及尚未接入的专门模板须按来源报告补齐后才能算 P4 完整。
